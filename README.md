## 四问当前主线

- 第一问：613个男胎抽血事件、167名孕妇；二次 Logit 混合效应模型，分离妇间 BMI 与个体内 BMI 变化。
- 第二问：167名孕妇的首次达标删失区间；对数逻辑斯蒂区间删失 AFT；BIC 主分组为1组，两组只作敏感性。
- 第三问：计划时可得多因素的 Logit 浓度混合模型；167名孕妇逐人留一；BIC 主分组为1组。
- 第四问：605条女胎记录、147名孕妇；以 AB 为目标的 L1 正则多因素逻辑回归，AE只作冲突审计。

第二、三问题面未提供最低可接受达标概率或风险数值权重，因此正式材料保留完整逐日前沿，不设置自行给定的 `q` 或虚构唯一最佳日。第四问题面未提供漏诊/误报代价比，因此不设置类别权重、SMOTE、代价比或唯一临床阈值。

## 使用边界

1. 第一问结论是附件数据范围内的观察性关联，不代表因果关系或临床外部验证。
2. 每问只以 `README_当前有效版本.md` 指向的 2026-08-25 正式复现包为当前版本；仓库中既有历史材料只作溯源。
3. `99_临时中转`、缓存、凭据和未审核候选不进入仓库。
4. 当前阶段不新增图片；待制图内容以 MATLAB/SVG 提示词 TXT 交付，原有历史图片保留。
5. 原始竞赛附件随仓库公开，仅用于本题复现和学习；使用者仍应遵守赛事、数据和引用要求。
