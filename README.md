## 第一问当前主模型

设 \(t_{ij}=\text{孕周}_{ij}-18\)，\(\bar B_i\) 为第 \(i\) 名孕妇的平均 BMI，\(d_{ij}=B_{ij}-\bar B_i\)，则推荐模型为

\[
\begin{aligned}
\operatorname{logit}(Y_{ij})={}&\beta_0+\beta_1t_{ij}+\beta_2t_{ij}^2
+\beta_B(\bar B_i-32)+\beta_Wd_{ij}\\
&+\beta_A(\text{年龄}_i-29)+\beta_P\text{生产次数}_i
+u_{0i}+u_{1i}t_{ij}+\varepsilon_{ij}.
\end{aligned}
\]

主要结果：孕周总体关系显著；约16周后 Y 浓度稳定上升；孕妇平均 BMI 每增加 1 kg/m²，Y 浓度平均降低约 0.191 个百分点；同一孕妇短期 BMI 偏差的独立关联不显著。完整解释以正式模型稿和主审报告为准。
