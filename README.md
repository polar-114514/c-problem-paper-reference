## 一键复现

在仓库根目录使用Windows PowerShell，并把输出放在仓库外：

```powershell
& ".\05_公共材料\06_核心代码索引\一键复现当前四问.ps1" `
  -输出根目录 "C:\temp\C题四问复现"
```

脚本会依次运行第一至第三问主分析、补充审计、第四问完整建模，并逐字节核对原始附件和26张批准核心结果表；联合核对状态必须为`PASS`。

## 使用限制

1. 所有模型结论仅适用于附件样本和相应统计口径，不作因果或临床外部验证表述。
2. 引用数字时应同时记录对应核心结果CSV，不能手工改写数值。
3. 后续新增图表统一使用MATLAB生成SVG；本分支保留已有SVG及相邻TXT提示词。
4. `06_论文总稿`仅提供写作框架，正文和最终提交包仍由论文手完成。
