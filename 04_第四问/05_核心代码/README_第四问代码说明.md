# 第四问核心代码说明

`第四问女胎异常判定建模.py`是第四问完整主建模程序。模型计算逻辑未改动，只增加了附件、题目、合同和输出目录的命令行参数，使整理后的工作区可以直接复现。

## 代码覆盖内容

- AB标签和女胎记录构造；
- 训练折内中位数填补、变换与标准化；
- 三标准差Z值规则、L1正则逻辑回归和BIC剪枝树；
- 逐孕妇外层留一与训练内阈值选择；
- PR-AUC、ROC-AUC、MCC、校准和整簇区间；
- T13、T18、T21分型模型及阈值性能曲线。
