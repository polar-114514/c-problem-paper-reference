# 第四问复现入口

## 一键运行

在 Windows PowerShell 5 或 PowerShell 7 中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\一键运行第四问女胎异常判定.ps1
```

脚本从工作区 `00_题目与原始资料/02_原始数据/附件.xlsx` 的“女胎检测数据”工作表重建全部输入，不读取预审输出或手工中间表。正式结果写入 `正式候选输出`。

## 计算范围

- 三标准差 Z 值规则基准；
- L1 正则多因素 Logistic；
- BIC 剪枝决策树；
- 147 名孕妇逐人留一；
- 每个外层训练集内 5 折分层分组选择正则强度与 MCC 参考阈值；
- 400 次孕妇整簇验证指标区间；
- T13、T18、T21 分型验证；
- 阈值完整曲线、校准、敏感性、参数来源、内部总控审核和文件哈希。
