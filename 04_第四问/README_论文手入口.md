# 第四问论文手入口

本目录只保留第四问论文写作需要的标签口径、推荐模型卡、候选比较、主要评价结果、参数表、制图提示词和主建模Python代码。逐记录预测、逐次整簇自助、复核脚本和运行环境仍位于后台材料。

当前主路线为L1正则多因素逻辑回归。目标标签采用AB列非整倍体提示，AE列“胎儿是否健康”不能替代AB。训练、调参和验证均按孕妇分组，模型输出只用于筛查辅助，不是临床确诊。
