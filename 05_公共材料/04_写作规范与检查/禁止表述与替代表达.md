# 禁止表述与替代表达

| 禁止或高风险表述 | 建议替代表达 |
|---|---|
| 683后数据无效 | 683前后关系存在异质性；后段失败概率信息不足 |
| BMI没有影响 | 数据未识别出稳定离散BMI切点，模型仍保留BMI连续效应 |
| 算法自动得到题面五组 | 数据未识别稳定切点；为回答题目分组要求，按题面五组给出实施结果 |
| 14周2天是临床最佳时点 | 14周2天是声明决策规则下的样本内统计折中时点 |
| 第三问显著优于第二问 | 多因素调整后的点损失较低，但差值区间包含0 |
| 模型确诊染色体异常 | 模型预测附件AB筛查提示，用于筛查辅助而非确诊 |
| P=0 | P值低于数值显示范围，或报告科学计数法 |
| 系数证明因果作用 | 系数反映附件样本中的调整关联 |
