# 核心代码入口

为方便论文写作、代码附件整理和当前结果复现，每问目录保留`05_核心代码`：

- 第一至第三问各保留两个联合主脚本的同步副本；
- 第四问保留完整主建模脚本、题意合同和单问运行入口；
- 复核脚本、报告生成脚本、依赖目录和历史代码仍在后台，不混入论文目录。

代码与模型函数、结果文件和SHA256的对应关系见`核心代码与模型对应表.csv`。

当前四问统一复现入口为`一键复现当前四问.ps1`。它显式指定输入、冻结依赖和临时输出目录；`核对当前四问复现结果.py`随后把26张实质性结果表与当前批准核心表逐字节对照。`生成论文补充证据.py`只刷新中心化常数、分组稳定性和第四问区间/阈值摘要，不重新拟合模型。所有材料修改完成后，运行`刷新论文材料哈希清单.py`重建外层完整性清单。
