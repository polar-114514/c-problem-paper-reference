# 公共材料入口

本目录用于论文手统一组织四问，不重复存放代码正文；各问核心代码位于对应问题目录，本目录提供统一代码索引。逐次重采样结果、全量预测和历史废弃模型仍位于后台。

建议阅读顺序：

1. `00_论文整体框架.md`；
2. `01_统一符号与口径/四问衔接关系.md`；
3. `01_统一符号与口径/统一符号表.csv`；
4. `02_统一模型与结果/核心结论与证据索引.md`；
5. `03_论文图表规划/论文图表总清单.csv`；
6. `04_写作规范与检查/论文手使用说明.md`；
7. `06_核心代码索引/README_核心代码入口.md`。

当前保留的11张SVG及其使用限制见`03_论文图表规划/已有图表使用状态.csv`。旧模型图只保留在后台，不进入论文目录。

论文手应从这里确定整篇论文结构，再进入各问题目录提取模型和结果。所有正文由论文手撰写；本工作区只提供经过审核的数学模型、证据表和写作边界。
