## 五个论文材料目录的统一结构

- `01_模型说明`：经过审核的模型目标、公式、估计方法和接口；
- `02_核心结果`：论文表格与图表可直接引用的CSV；
- `03_图表与提示词`：已有SVG、相邻的原提示词，以及后续MATLAB重绘提示词；
- `04_写作边界`：允许表述、禁止表述和解释限制；
- `05_核心代码`：当前主模型的原样代码副本和论文使用说明。

公共材料另外提供统一符号、四问样本口径、模型总览、论文图表清单、写作检查和待补参考文献清单。
