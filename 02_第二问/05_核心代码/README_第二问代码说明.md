# 第二问核心代码说明

本目录中的两个Python文件是当前第一至第三问主脚本的同步论文参考副本。统计逻辑与第一问目录对应脚本一致；补充脚本增加了可迁移的AFT冻结证据路径接口。

## 对应关系

- `优先问题整改分析.py`：包含二项GEE候选拟合、按孕妇分组交叉验证、计划日达标概率预测、时点最小最大折中、整簇重采样和检测误差传播；
- `补充主审整改.py`：包含`第二问BMI切点审计`、单切点搜索、BIC比较、折间稳定性、整簇稳定性和`统计主分组时点`。

## 论文写作建议

正文算法流程可概括为：

1. 按孕妇分组验证达标概率候选模型；
2. 用BIC、训练折和整簇重采样联合判断BMI切点稳定性；
3. 用无权重最小最大规则计算折中时点；
4. 用整簇重采样和检测误差传播给出不确定性。

正式重跑统一使用`05_公共材料/06_核心代码索引/一键复现当前四问.ps1`。该入口从本工作区读取附件和冻结证据，输出到`99_临时中转/当前四问一键复现`，不依赖已经迁走的历史目录。
