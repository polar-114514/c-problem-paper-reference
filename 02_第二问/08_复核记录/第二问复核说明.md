# 第二问建模复核说明

> 复核对象：`04_代码/第二问_时点优化求解.py` 及其结果。状态：**待主审/用户正式审核**；本分支先行归档。

## 复核要点

1. **口径一致性**：沿用第一问固定效应系数与方差分量；主样本 = 序号<683 且孕周∈[10,26) 男胎，613 事件 / 167 孕妇。只读取第一问冻结样本，未改动原数据。
2. **前瞻性输入**：分组/预测用**首测（基线）BMI**，避免用全程平均 BMI 造成的未来信息泄漏（第一问模型稿 §8 明确要求）。
3. **结果自洽**：BMI 越高 → 达标时间越晚 → 最优时点越晚；目标达标比例 \(c\) 越高 → 时点越晚；误差放大 → 时点轻微后移。三者方向均单调、符合预期。

## 已暴露的关键局限（需在正式定稿前处理）

1. **"二元达标时间"会塌缩**：若按"固定阈值求达标周"，第一问边际概率下标准 BMI 人群在窗口起点（10 周）已"50% 达标"，导致达标时间退化、分组失效。**应使用"概率型达标比例" \(p_g(t)=\bar p_i(t)\)**（本分支已采用）。
2. **风险函数权重敏感**：当 \(\lambda_1=\lambda_2=1\) 且 \(r(t)\) 用分段风险时，风险函数型倾向给出最早周（10 周）。**建议以机会约束型为主线**，或修正风险项以纳入"检测失败→重测→延迟确诊"的连锁后果，并对 \(\lambda\) 做敏感性分析。
3. **样本特征**：样本高 BMI 居多（均值 31.95），群体整体较早在窗口内达标，BMI 梯度主要在高 BMI 端体现。
4. **可解释性**：以"概率型达标比例"为介，避免了"人群平均浓度窗口内已 ≥4%"带来的解释偏差。
