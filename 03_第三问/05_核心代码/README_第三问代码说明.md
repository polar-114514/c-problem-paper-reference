# 第三问核心代码说明

本目录中的两个Python文件是当前第一至第三问主脚本的同步论文参考副本。统计逻辑与第一问目录对应脚本一致；补充脚本增加了可迁移的AFT冻结证据路径接口。

## 对应关系

- `优先问题整改分析.py`：通过`角色变量`构造第三问多因素特征，拟合多因素二项GEE，并由`对比第二三问增益`计算逐孕妇损失差及整簇区间；
- `补充主审整改.py`：在沿用第二问BMI分组裁决的前提下计算第三问统计主时点和两类不确定性区间。
