# 第三问当前有效版本

## 当前主版本

- 完整复现包：`04_代码/第三问多因素达标比例完整复现包_20260825`。
- 模型：对 Y 染色体浓度作 logit 变换后的线性混合效应模型；固定效应为孕周、首次 BMI、首次年龄、首次身高和首次生产次数，随机结构为孕妇随机截距与标准化孕周随机斜率。
- 统计单位：167 名孕妇、613 个抽血事件；18 个严格技术复测组、36 条复测记录用于估计检测误差，不当作独立样本扩充。
- 决策时信息：仅使用计划检测时已经可得的孕周与首次基线变量；体重因由 BMI 和身高代数确定而不重复入模；本次及未来 Y 浓度、Z 值、测序质控量和后续 BMI 均禁止进入预测变量。
- 候选裁决：5 条同目标路线均完成 167 名孕妇逐人留一。二次孕周浓度模型虽有更低平均预测损失，但在 10 至 25 周出现反向概率段，未通过边界闸门；最终选择多因素线性浓度混合模型。
- 预测验证：入选模型逐孕妇平均对数损失为 0.459108，Brier 分数为 0.148597，孕妇等权 ROC-AUC 为 0.716546，PR-AUC 为 0.906742。相对同路线第二问信息集基准，对数损失差的 95% 区间为 [-0.040448，-0.001581]；Brier 差区间跨 0，因此只把对数损失改进作为确定证据。
- 多因素不确定性：首次 BMI、首次年龄和首次生产次数的 400 次整簇自助区间分别保持负、负、正方向；首次身高区间跨 0，不能写成稳定独立效应。
- BMI 分组：在全部 1 至 139 个可识别组数中，等孕妇权重复合似然 BIC 选择 1 组。两组挑战切点为 36.436175，人数为 151/16；两组挑战在整簇自助中仅 13.5% 胜出、检测误差传播中 0% 胜出，只保留为敏感性结果。
- 两组挑战采用连续、无空档的决策区间：`[20.703125,36.436175)` 与 `[36.436175,46.875000]`；分组表和逐日前沿使用同一切点。
- 时点输出：题面没有给出延迟与未达标的代价比，也没有最低可接受达标比例，故不设置 `q`、风险权重或虚构的唯一最佳日；正式输出为各 BMI 方案的逐日“检测时点—尚未达标概率”帕累托前沿。10 周早于样本最早观测 11 周，已标为边界外推。
