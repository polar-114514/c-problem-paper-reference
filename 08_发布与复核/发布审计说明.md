# GitHub 发布审计说明

## 发布原则

- 仓库名称：`c-problem-paper-reference`。
- 可见性：公开；由用户明确授权公开。
- 用途：论文手参考、四问审核结果查阅和代码复现。
- 当前发布范围：题目原始资料、第一至第四问已审核当前材料、分类镜像、联合总审和最终工作区复核。
- 论文总稿与最终提交不由建模代理写入正文。

## 纳入内容

1. `00_题目与原始资料`：原题 PDF、原始 Excel 附件。
2. `01_第一问`至`04_第四问`：当前有效版本说明、正式复现包、论文手分类镜像和复核记录。
3. `05_公共材料`：统一口径说明、52项联合总审和50项最终工作区复核。
4. 仓库 README、忽略规则、发布清单及只读校验脚本。

## 明确排除

- `node_modules`、`__pycache__`、`.pyc` 和编辑器缓存；
- 格式规范变更前的历史 PNG；
- 两个 ZIP 重复件；
- `99_临时中转` 中尚未审核或仅供试验的材料。

本次只增量同步四问当前正式包及其审核通过的分类镜像；仓库中既有历史材料予以保留，但不得替代各问`README_当前有效版本.md`所指版本。排除不等于删除，本地正式工作区和临时备份均未被改动。

## 隐私与安全检查

- 高置信 GitHub、OpenAI、AWS 密钥模式：0。
- 文本邮箱模式：0。
- 原始 Excel 中手机号、身份证号、邮箱模式：均为0。
- 大于20 MB的文件：0。
- 原始竞赛附件包含去标识化孕妇代码、日期、年龄和检测指标；用户已明确授权随公开仓库发布。仓库内未发现手机号、身份证号、邮箱或高置信凭据模式。

## 可追溯性

`已审核材料清单.csv` 记录每个提交文件的相对路径、大小、SHA256、来源类型和审核状态。运行 `python tools/verify_repository.py` 可以核对清单、题目附件哈希、四问审核PASS记录、正式包图表边界、禁入文件及高置信敏感模式。

本次发布前清单共725条；仓库级校验结果为通过，错误数0。

远端复核：仓库可见性为PUBLIC，默认分支为`main`；协作者`rushu3000`与`pupu-cmd`均保有push权限。
