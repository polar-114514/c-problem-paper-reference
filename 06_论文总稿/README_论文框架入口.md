# 论文总稿入口

`..\05_公共材料\00_论文整体框架.md`

写作时同时使用：

- `..\05_公共材料\01_统一符号与口径\统一符号表.csv`；
- `..\05_公共材料\02_统一模型与结果\核心结论与证据索引.md`；
- `..\05_公共材料\03_论文图表规划\论文图表总清单.csv`；
- `..\05_公共材料\04_写作规范与检查\提交前证据检查清单.md`。

第一至第四问正文材料分别从`01_第一问`至`04_第四问`读取；核心代码从各问`05_核心代码`整理到最终代码附件，历史代码不得混入总稿目录。
