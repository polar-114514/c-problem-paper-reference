# 第一问候选模型验收表

| 验收维度 | 通过条件 | 否决条件 |
|---|---|---|
| 题意对应 | 直接解释孕周、妇间 BMI 与个体内 BMI 的关联 | 只追求预测，无法回答相关特性 |
| 样本口径 | 613 个主事件、167 名孕妇，A055 歧义事件排除 | 混入 683 后机制段或把技术复测当独立样本 |
| 重复测量 | 孕妇随机效应、GEE 或孕妇聚类稳健推断；随机斜率按收敛、非奇异与信息准则选择 | 使用普通独立样本标准误且不修正，或错误地仅凭新孕妇固定效应CV否决随机斜率 |
| 显著性 | 对整个非线性项或变量组进行联合检验 | 只挑选某个基函数 p 值或只看相关系数 |
| 泛化验证 | 按孕妇分组；报告组外 RMSE、MAE、R² | 随机按行切分，导致同一孕妇泄漏 |
| 稳健性 | 至少两种预先指定敏感性分析方向一致 | 结论仅由少量强影响孕妇或单一变换支撑 |
| 可解释性 | 能给出原 Y 浓度尺度上的效应和范围 | 只能输出黑箱重要性 |
| 简洁性 | 非线性自由度与交互均有证据支持 | 无证据堆叠高阶项、样条和交互 |
| 可复现性 | 一键脚本、固定随机种子、中文结果表、哈希清单 | 手工步骤或关键参数未记录 |
| 图形规范 | 不实际绘图；仅提交 MATLAB-SVG 制图提示词 TXT | 新增任何图像文件 |

## 主审决策顺序

先检查数据口径和泄漏，再检查模型收敛与显著性，然后比较按孕妇分组的泛化误差，最后比较简洁性。任一硬性否决项触发后，该路线不能成为论文主线；仍可作为稳健性对照。
