# 候选 A：低阶多项式混合效应模型设计

> 当前文件只锁定建模方案，不含拟合结果。待 `00_共同口径` 中冻结数据生成后，所有数值由可复现脚本计算。

## 1. 建模目的

在不把同一孕妇的多次检测当成独立个体的前提下，刻画男胎 Y 染色体浓度与孕周、BMI 及少量孕妇特征之间的关系，并分别检验孕周效应、BMI 妇间效应与 BMI 个体内效应是否显著。候选 A 强调公式简洁、参数含义直接和论文可解释性。

## 2. 数据口径

1. 主样本限定为序号小于 683 且孕周属于 `[10,26)` 的男胎记录。
2. 以 `孕妇代码 B + 检测抽血次数 I` 定义一次抽血事件。
3. 同一抽血事件的多次 Y 测量在原始比例尺度上取算术均值，作为该事件的浓度估计；同时保留检测记录数、组内标准差和极差，确保聚合过程可审计。每次抽血事件在主模型中权重相同，不因复测次数较多而自动获得更大权重。
4. `A055` 第 3 次抽血的孕周元数据冲突，整次事件不进入主拟合；在敏感性分析中分别代入两条原始孕周，但不得取均值或中位数。
5. 孕周以题目 J 列为准。序号、Y 染色体 Z 值、非整倍体结果和出生健康结局不作为预测变量。
6. 主模型不同时纳入 BMI、身高和体重，避免对同一体型信息重复解释。

## 3. 符号与变量变换

记孕妇为 `i`，其第 `j` 次抽血事件为 `j`：

- `Y_ij`：抽血事件聚合后的 Y 染色体浓度，取值为 0 到 1 的比例；
- `Z_ij = log(Y_ij / (1-Y_ij))`：Y 浓度的 logit 变换；
- `T_ij`：孕周减去主样本平均孕周后的中心化值；
- `Bbar_i`：孕妇 `i` 在主样本中的事件级 BMI 均值；
- `B_between_i`：`Bbar_i` 减去主样本妇间 BMI 均值，表示不同孕妇之间的 BMI 差异；
- `B_within_ij = BMI_ij - Bbar_i`：表示同一孕妇相对自身平均 BMI 的偏离；
- `A_i`：中心化年龄；
- `u_i`：孕妇随机截距；
- `epsilon_ij`：事件级残差。

## 4. 候选模型族

### 4.1 随机截距空模型

用于估计同一孕妇重复测量带来的组内相关性：

`Z_ij = beta_0 + u_i + epsilon_ij`。

由随机截距方差和残差方差计算组内相关系数 ICC，以判断普通独立回归是否不合适。

### 4.2 线性主效应模型

`Z_ij = beta_0 + beta_T*T_ij + beta_B*B_between_i + beta_W*B_within_ij + gamma'*X_i + u_i + epsilon_ij`。

该式将 BMI 的妇间差异和个体内变化分开：`beta_B` 回答“不同孕妇之间 BMI 较高时 Y 浓度如何变化”，`beta_W` 回答“同一孕妇 BMI 相对自身平均水平改变时 Y 浓度如何变化”。

### 4.3 低阶曲率与交互模型

主候选关系式为：

`Z_ij = beta_0 + beta_1*T_ij + beta_2*T_ij^2 + beta_3*B_between_i + beta_4*B_between_i^2 + beta_5*B_within_ij + beta_6*T_ij*B_between_i + gamma'*X_i + u_i + epsilon_ij`。

其中二次项允许孕周和妇间 BMI 的关系在研究区间内平缓弯曲；交互项允许 BMI 不同的孕妇具有不同的孕周增长趋势。为控制复杂度，不加入三次项、`T^2 × BMI` 等高阶交互。

预测到原始浓度尺度时采用：

`Yhat_ij = 1 / (1 + exp(-Zhat_ij))`。

## 5. 模型比较与显著性检验

1. 固定效应模型比较统一用最大似然法拟合；最终参数估计可用限制最大似然法复拟合。
2. 对孕周块、BMI 块和孕周-BMI 交互块分别做嵌套模型似然比检验，而不是只挑单个系数的 p 值。
3. 线性主效应模型与二次交互模型同时报告 AIC、BIC、边际/条件解释度以及按孕妇分组的交叉验证误差。
4. 五折交叉验证按孕妇代码划分，测试折中的孕妇从未出现在训练折；对新孕妇的预测仅用固定效应，不使用其未知随机截距。
5. 重复分组交叉验证使用预先固定的随机种子；主要指标为原始浓度尺度的 RMSE、MAE 和组外决定系数。候选 A 不把预测浓度直接误当成“达标概率”，因此本阶段不计算未经概率模型校准的 Brier 分数。
6. 用按孕妇整簇重抽样的 bootstrap 复核关键效应方向和区间稳定性。

固定效应曲率只有在整块似然比检验显著、分组验证误差至少改善 0.5%，且各重复轮次方向一致时保留。随机斜率属于协方差结构；新孕妇的固定效应预测不能充分评价它，因此随机斜率按收敛、非奇异、AIC/BIC 均至少改善 2 且组外误差不明显恶化进行判断，不要求它必须改善新孕妇固定效应 RMSE。

## 6. 辅助指标的处理

年龄和生产次数作为预先指定的主临床调整项。辅助生殖标志虽然记录完整，但只来自 3 名孕妇（11 个事件），簇层支持过稀，因此仅进入敏感性模型；这项处理在拟合前依据数据支持度确定，不是按 P 值筛选。怀孕次数缺失 167/613，不进入主调整，也不通过完整病例分析额外丢失 48 名孕妇。GC 含量、读段数、比对率、重复读段比例和过滤比例仅用于测量机制敏感性调整，不与核心临床关系混写。
