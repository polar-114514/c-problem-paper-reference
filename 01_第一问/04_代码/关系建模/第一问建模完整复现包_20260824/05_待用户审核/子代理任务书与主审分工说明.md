# 第一问子代理任务书与主审分工说明

以下是本轮多路线建模采用的可复用任务提示词。所有子代理只能产出候选证据，最终路线由主代理在统一口径下复算并审核。

## 共同前置提示词

```text
你负责第一问的一条独立候选建模路线。只读取已冻结的主模型样本，不改原始附件，不进入第二至第四问。分析单位必须是抽血事件，主样本必须为613个事件、167名孕妇；同一孕妇重复测量必须被处理。BMI必须拆为妇间均值和个体内偏差。全部结论只写观察性关联。

你必须输出：模型公式与每项含义、模型选择依据、整体显著性检验、效应量与95%区间、按孕妇分组的组外验证、收敛/奇异性/异方差/共线性/强影响检查、至少两项敏感性分析、可复现代码和全中文表头CSV。不得生成图片；认为需要的图只写MATLAB-SVG制图提示词TXT。若路线不满足验收条件，应主动否决，不得强行推荐。
```

## 子代理 A：参数化层级模型

```text
在共同冻结口径下，比较孕周线性项、二次项和必要的低复杂度交互；建立孕妇随机截距模型，并检验中心化孕周随机斜率。响应尺度至少比较原Y尺度与Logit(Y)。重点回答：孕周是否非线性、妇间BMI和个体内BMI是否具有不同关联、随机斜率是否值得保留。模型比较固定效应时用ML；随机斜率方差在边界时不得机械报告普通卡方P值。输出原尺度边际效应，并给出自我否决条件。
```

## 子代理 B：受控非线性模型

```text
在同一冻结样本上，用自由度受控的自然样条或GAMM检查孕周曲线是否超出二次项能表达的范围。样条基函数不逐项解释P值；对整组非线性项做整体检验。必须与线性和二次模型在相同孕妇分组折上比较，并严格惩罚无验证增益的复杂度。BMI可探索二次项或与孕周交互，但只有整体检验和组外验证同时支持才允许保留。给出可解释的曲线特征，不生成图。
```

## 子代理 C：比例边界与分布稳健路线

```text
把Y浓度视为(0,1)比例变量，尝试变精度Beta回归、分数Logit GEE及必要的Gaussian GEE对照。标准误必须按孕妇聚类稳健，或通过整名孕妇簇自助获得。检查结论是否依赖正态混合模型、方差是否随均值或孕周变化。重点复核孕周曲线、妇间BMI负关联、个体内BMI不显著三项结果。若方法不能显式表达孕妇随机斜率，必须在报告中说明，只能作为稳健性对照。
```

## 主代理审核提示词

```text
不要按子代理各自的指标直接投票。先核对样本哈希、事件数、孕妇数、变量定义和交叉验证泄漏，再在同一冻结样本和同一折分下重拟合核心候选。依次审核：题意匹配、数据层级、比例边界、整体显著性、效应区间、模型复杂度、组外验证、残差性质、稳健性和可复现性。

只选择一条论文主线。复杂模型若没有明确的整体检验或组外增益，应删除；预测略优但统计假设明显失效的模型只能作敏感性；无法表达个体层级的模型只能作独立稳健性。最终结论必须区分妇间与个体内BMI、区分显著与证据不足、区分关联与因果，并明确模型的预测边界。
```

## 最终职责边界

子代理负责“提出并尽力证伪候选路线”，主代理负责“统一复算、纠错、取舍和最终签字”。本轮主代理据此选择二次 Logit 随机斜率混合模型为唯一主线，并将 Beta/GEE、样条和原尺度模型降为稳健性或敏感性材料。
