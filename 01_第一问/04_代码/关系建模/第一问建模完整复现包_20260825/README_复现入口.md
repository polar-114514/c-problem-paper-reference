# 第一问完整复现入口

在本目录打开 PowerShell，执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\一键运行第一问完整复现.ps1
```

流程会从工作区原始附件重新生成冻结数据，依次运行候选与推荐模型、孕妇级交叉验证、400次主簇自助、200/400/800次自助收敛检查、3至10折计算设置敏感性以及总控验收。任一步失败都会返回非零退出码。

要求保持本复现包位于“C题论文工作区”的任意后代目录；脚本会向上寻找`00_题目与原始资料/02_原始数据/附件.xlsx`，不依赖固定用户名或绝对路径。

本流程不生成图片；待制图内容位于`06_制图提示词`。

`05_待用户审核`及个别文件名中的“待审核”是归档前流程命名，为保留证据链未改名；其当前状态以`07_总控追加复核/第一问总控复核材料/第一问自审PASS记录.json`为准。
