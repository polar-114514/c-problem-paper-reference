# 第一问数据审计：数据来源与复现说明

## 结论

本次“数据质量与结构审计”的核心流程可在本机从原始 Excel 一键重跑。复现范围包括：源文件校验、数据提取、审计计算、两套本机独立复算、12 个中文表头 CSV、MATLAB 绘图数据和 8 张纯矢量 SVG；另以远端 Wolfram Language 内核进行事件层级交叉复核。这一流程只做审计，不做第一问正式关系模型拟合。

## 原始数据唯一性

- 源文件：00_题目与原始资料/02_原始数据/附件.xlsx
- 本次审计使用工作表：男胎检测数据
- 使用区域：A1:AE1083，含 1 行表头和 1082 条记录，共 31 列
- 原始文件 SHA-256：14827156218bd4f7e4f16db4aa6d9f757c6648379e038ae6c6b58383648614af
- 一键脚本默认强制校验该哈希；源文件变化时会立即停止，避免将不同版本的数据当成同一次结果。

## 数据是怎样产生的

| 阶段 | 输入 | 处理 | 产物 |
|---|---|---|---|
| 1. 只读提取 | 原始附件.xlsx | 逐工作表读取已使用区域，不改动 Excel | 男胎/女胎 JSON 快照与源数据清单 |

| 3. 独立 Python 审计 | 原始 Excel | 使用 pandas/openpyxl 直接再读一次原表，重算核心口径和逐行标志 | 独立审计 JSON、逐行标志 CSV |
| 4. 独立 JavaScript 复算 | 男胎 JSON 快照 + 主审计汇总 | 不调用主审计函数；以硬编码基线和生成结果双重比较，覆盖样本集合、四种事件键、离散度、阈值翻转、A055冲突及683/687断点 | 222/222 校验清单 |

## 固定口径

1. 主参考样本：序号＜683，孕周位于 [10,26)，核心字段合法，共 674 条、167 名孕妇、614 个抽血事件。
2. 敏感性样本：序号＜683，孕周不超过 25周0天，核心字段合法，共 670 条。
3. 事件层级：孕妇B → 抽血事件B+I → 检测会话B+I+H → 检测记录A；B+I+H+J仅作严格元数据一致性诊断。全表对应1021/1063/1082条，严格组为1064个。
4. 全部 1082 条原始记录均保留，硬删除数为 0；序号≥683 作为候选数据生成机制分段保留和标记，附件不足以确认其实验室原因。

## 一键复现方法

在 PowerShell 7 中执行：

    & ".\01_第一问\04_代码\数据质量与结构审计\一键复现数据审计.ps1"

默认在 99_临时中转 下新建带时间戳的复现目录，不覆盖归档结果。每次复现都生成“复现结果清单.json”，记录环境版本、口径、代码哈希、产物哈希和验收结果。

## 可复现性的边界

- 核心数据审计和 MATLAB SVG 在本机可一键复现。
- “可复现”以源哈希、表结构、关键数值、口径计数和图形结构通过为准；提取时间、运行目录及工具内部工作簿 ID 会随运行变化，因此带这些运行元数据的 JSON 不要求跨次字节完全相同。
- 旧 Wolfram 文件保留为“事件层级修订前历史口径”，不得引用其中把40组全部称作技术复测的表述。
- 本次远端 Wolfram Language 15.0.1（Linux-x86-64）只读取从原表精简转录的六字段载荷，载荷 SHA-256 为 `d87f39f2909841601aa67c3ec02573e8c411eeb77de2b130fc798d2528e1ee1e`；载荷、生成器、Wolfram Language代码及机器可读结果均已归档。它没有直接读取本地 Excel，也不表示本机Windows安装了Wolfram内核。远端接口依赖外部状态，因此不纳入本机一键必过条件。
- 一键流程的必过条件是：源哈希一致、1082 条原始记录、674/670 两种口径一致、JavaScript 222/222 通过、12 个 CSV 表头符合规范、8 张 MATLAB SVG 且不含嵌入位图。
