# 第一问数据审计字段字典与取值说明

## 命名规则

- 对外交付的 12 个 CSV 表头全部使用中文，英文字段代码只在程序内部使用。
- 比例类字段在表头中显式标出“比例，0–1”或“%”；孕周、BMI、天数、条数等均显式标出单位。
- True/False 是布尔标志的机读取值；字段含义以中文表头为准。
- HARD_EXCLUDE、EXCLUDE_PRIMARY_KEEP_SENSITIVITY、KEEP_PRIMARY_MARKED、KEEP_PRIMARY_CLEAN 是审计处置类别的稳定机读编码，不是表头。

## 关键派生字段

| 中文字段 | 来源或公式 | 用途 |
|---|---|---|
| 检测记录标识 | 原表序号A | 唯一标识一条检测记录 |
| 解析检测孕周（天） | 将原表“检测孕周”中的 w 与 w+d 统一换算为 7×周+天 | 统一孕周标尺 |
| 解析检测孕周（周） | 解析孕周（天）÷7 | 统计与绘图 |
| 抽血事件标识 | 孕妇代码B + “#” + 检测抽血次数I | 按题目字段定义操作性抽血事件；附件不能单独证明所有多记录组都来自同一物理血样 |
| 同一抽血事件检测记录数（条） | 按B+I分组计数 | 区分单记录抽血事件与多次检测/可能复检 |
| 孕妇－检测日期会话标识（B+H） | 孕妇代码B + 规范化检测日期H | 日期会话辅助口径；H是检测日期，不是采血日期 |
| 检测会话标识（B+I+H） | 孕妇代码B + 抽血次数I + 规范化检测日期H | 识别同一抽血编号在同一检测日的多条记录 |
| 严格元数据一致组标识（B+I+H+J） | 检测会话标识再加解析孕周J | 只作元数据冲突诊断，不用于把抽血事件拆开 |
| 同一抽血事件孕周冲突标志 | 同一B+I内解析孕周唯一值数大于1 | 标出A055第3次抽血等冲突；聚合时不取均值或中位数人为定值 |
| 日期推算孕周－记录孕周（天） | 检测日期－末次月经－解析孕周天数 | 检查日期与孕周一致性，不替代原表孕周 |
| 由身高体重重算的孕妇BMI（kg/m²） | 体重kg÷(身高m)² | 检查原表 BMI 算术一致性 |
| 参考主样本纳入标志 | 核心字段合法、序号＜683、孕周位于 [10,26) | 已确认的主口径，674 条 |
| 截至25周0天敏感性样本纳入标志 | 核心字段合法、序号＜683、孕周位于 [10周0天,25周0天] | 较严格的敏感性口径，670 条 |
| 序号683及以后批次标志 | 序号≥683 | 标记候选数据生成机制断点后的记录，不做硬删除；无外部元数据时不解释为已确认实验室批次 |
| 参考主样本排除原因 | 核心字段非法、683批次、主孕周窗外三类原因的组合 | 保留每条记录为何不进入主口径的可追溯说明 |
| 仅标记不排除原因 | 复测、日期偏差、GC边界、测序读段异常、Y浓度阈值/异常值等标志的组合 | 实现“零硬删除、先标记” |

## 口径边界

- 主窗口 [10,26) 等价于 10周0天至25周6天。
- “截至25周0天”敏感性口径包含 25周0天当天，不包含 25周1天至25周6天。
- 四层固定结构为：孕妇B → 抽血事件B+I → 检测会话B+I+H → 检测记录A；B+I+H+J仅作严格元数据一致性诊断。
- 全表共有1021个B+I抽血事件、1063个B+I+H检测会话和1082条记录；B+I+H+J严格组为1064个。
- 全部 1082 条原始记录都保留；逐行标志表不代表已经开始正式建模。
